Converter Lite

Jenis Karya: Website
Nama Karya: Converter Lite
Pengembang: Egy Noval Davyan Pratama dan dovin musyafa yusuf
Kelas: XI-TKJ-01, SMKN 01 Nganjuk

1. Latar Belakang Ide

Dalam kehidupan sehari-hari, banyak orang yang membutuhkan alat sederhana untuk membuat kode QR maupun password aman. Misalnya, guru ingin membagikan tautan Google Form dalam bentuk QR agar mudah diakses siswa, atau siswa ingin membuat password kuat untuk akun sekolah.
Dari permasalahan tersebut, dibuatlah Converter Lite, sebuah website sederhana yang membantu pengguna membuat QR code dan password secara cepat, aman, dan praktis.

2. Tujuan dan Manfaat

-Mempermudah pembuatan kode QR untuk berbagai kebutuhan sekolah atau pribadi.
-Membantu pengguna membuat password aman tanpa perlu menginstal aplikasi tambahan.
-Memberikan contoh penerapan logika pemrograman JavaScript dalam kehidupan nyata.
-Menunjukkan kemampuan pengembangan website interaktif berbasis HTML, CSS, dan JavaScript.


3. Deskripsi Karya

Converter Lite adalah website dua fungsi:

-QR Code Generator
Mengubah teks atau tautan menjadi kode QR dan memungkinkan pengguna mengunduhnya sebagai file PNG.
-Password Generator
Membuat password acak berdasarkan panjang karakter serta pilihan huruf besar, angka, dan simbol.

4. Teknologi yang Digunakan

HTML5 – struktur halaman web
CSS3 – desain tampilan dan efek visual
JavaScript (Vanilla JS) – logika utama aplikasi
QRCode.js – library untuk membuat QR Code
Font Awesome – ikon navigasi antarmuka

5. Cara Menggunakan

Buka file index.html menggunakan browser (Google Chrome atau sejenisnya).
Pilih menu QR Generator atau Password Generator pada sisi kanan.
   Untuk QR Code: masukkan teks/tautan lalu klik Buat QR, hasil dapat diunduh.
   Untuk Password: atur panjang dan jenis karakter, lalu klik Buat Password.
Password yang dihasilkan dapat disalin dengan satu klik.

6. Kode Sumber (Source Code)

Proyek ini terdiri dari tiga file utama:

index.html      → Struktur halaman utama
css/style.css   → Tampilan dan layout
js/script.js    → Logika QR dan Password generator

7. Kesimpulan

Converter Lite membantu pengguna dalam dua hal utama: membuat QR Code dan menghasilkan password aman.
Website ini dibuat untuk menjawab kebutuhan praktis di lingkungan sekolah dan menjadi contoh nyata penerapan teknologi web sederhana dalam kehidupan sehari-hari.
